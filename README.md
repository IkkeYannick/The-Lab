
# The Lab

A collaborative web-based application designed to assist mechanics in hands-free work by connecting Meta VR headsets with web based remote support officers.

## Overview

This project enables mechanics to access technical blueprints and receive real-time guidance from support staff while maintaining hands-free operation. By integrating VR technology with web-based tools, The Lab streamlines complex mechanical repair and assembly tasks.

## Key Features

- **Meta VR Headset Integration** - Seamless connection to VR devices for immersive blueprint visualization
- **Remote Support** - Support officers can guide mechanics in real-time
- **Hands-Free Operation** - Mechanics work without interrupting their tasks
- **Blueprint Access** - Digital technical documentation available in VR environment
